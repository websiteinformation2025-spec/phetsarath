ຕົວແກ້ໄຂການຕັດຄຳລາວ ສຳລັບ Microsoft Word

Lao Text Fixer — a free Word add-in for Windows, macOS and Word on the web. No macros, no installers: it runs in Word's built-in add-in system.

ມັນເຮັດຫຍັງ?

ແກ້ໄຂບັນຫາ Word ບໍ່ຕັດຄຳລາວຂຶ້ນແຖວໃໝ່: ກົດປຸ່ມດຽວ ມັນຈະໝາຍຂໍ້ຄວາມລາວເປັນ complex script (ວິທີແກ້ທີ່ຖືກຕ້ອງ) ແລະ ສາມາດເພີ່ມ/ລຶບຈຸດຕັດຄຳທີ່ເບິ່ງບໍ່ເຫັນ (ZWSP) ສຳລັບ Word ຮຸ່ນເກົ່າ. ຂໍ້ຄວາມຂອງທ່ານບໍ່ອອກຈາກເຄື່ອງ — ທຸກຢ່າງເຮັດວຽກ ພາຍໃນ Word ເທົ່ານັ້ນ.

One click tags Lao runs with the complex-script properties Word's Lao word-break engine needs, and can insert/remove invisible syllable break points for old Word versions. Your text never leaves your machine. Free under the SIL OFL — same engine logic as our VBA macro, without the macro-security warnings.

ດາວໂຫລດ manifest.xml ກັບໄປໜ້າຟອນ

ວິທີຕິດຕັ້ງ · How to install

ອົງກອນ / ຫ້ອງການ (ແນະນຳ) — Microsoft 365 admin

Best for offices: an admin deploys it once to everyone (Windows, Mac and web at the same time).

  1. Microsoft 365 admin center → Settings → Integrated apps
  2. Upload custom apps → Office Add-in → Provide link to manifest file
  3. ວາງລິ້ງ: https://phetsarath.mts.la/addin/manifest.xml
  4. ເລືອກຜູ້ໃຊ້ → Deploy — ປຸ່ມ Lao Fixer ຈະປາກົດໃນແຖບ Home ຂອງ Word

Word ໃນເວັບ (ທົດລອງໄວທີ່ສຸດ) — Word on the web

  1. ເປີດເອກະສານໃນ Word on the web
  2. Insert → Add-ins → Upload My Add-in
  3. ເລືອກໄຟລ໌ manifest.xml ທີ່ດາວໂຫລດຈາກປຸ່ມຂ້າງເທິງ

macOS (Word for Mac)

  1. ດາວໂຫລດ manifest.xml ແລ້ວ copy ໄປທີ່:
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef
    (ຖ້າໂຟນເດີ wef ບໍ່ມີ ໃຫ້ສ້າງເອງ — Finder → Go → Go to Folder…)
  2. ປິດ-ເປີດ Word ຄືນ
  3. Insert → Add-ins ▼ (ລູກສອນລົງ) → Developer Add-ins → Lao Text Fixer

Windows (ບໍ່ມີ admin — shared folder)

  1. ສ້າງໂຟນເດີ ເຊັ່ນ C:\addins ແລ້ວວາງ manifest.xml ໃສ່
  2. ແຊໂຟນເດີ: ຄລິກຂວາ → Properties → Sharing → Share (ກັບຕົວເອງກໍໄດ້) ຈື່ network path ເຊັ່ນ \\YourPC\addins
  3. Word → File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs → ວາງ path → Add catalog → ຕິກ Show in Menu → OK → ປິດ-ເປີດ Word
  4. Insert → My Add-ins → SHARED FOLDER → Lao Text Fixer

ໃນອະນາຄົດພວກເຮົາວາງແຜນສົ່ງເຂົ້າ Microsoft AppSource ເພື່ອໃຫ້ຕິດຕັ້ງໄດ້ຈາກ store ໃນ Word ໂດຍກົງ · An AppSource listing is planned so it can be installed from Word's built-in store with one click.

ຄວາມປອດໄພ · Security

This is an Office Add-in, not a macro: it runs sandboxed in Word's add-in runtime, can only touch the open document, cannot access your files or system, and shows no security warnings. The complete source is readable at taskpane.html and laofix.js.

ນີ້ແມ່ນ Office Add-in ບໍ່ແມ່ນມາໂຄຣ: ມັນເຮັດວຽກໃນລະບົບ add-in ຂອງ Word ໂດຍກົງ ເຂົ້າເຖິງໄດ້ແຕ່ເອກະສານທີ່ເປີດຢູ່ເທົ່ານັ້ນ ບໍ່ສາມາດເຂົ້າເຖິງໄຟລ໌ ຫຼື ລະບົບຂອງທ່ານ ແລະ ບໍ່ມີຄຳເຕືອນຄວາມປອດໄພ. ໂຄດທັງໝົດເປີດເຜີຍໃຫ້ອ່ານໄດ້.
