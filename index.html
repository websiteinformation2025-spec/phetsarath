What was broken before — and what v4.103 fixes

ນ້ຳໜັກຕົວອັກສອນ

ສະບັບເກົ່າມີພຽງນ້ຳໜັກດຽວ — ກົດປຸ່ມ B ຫຼື I ໃນ Word ແລ້ວໂປຣແກຣມຕ້ອງປອມຕົວໜາເອງ ເຮັດໃຫ້ຕົວອັກສອນເປື້ອນ

໑໒ ຟອນແທ້: Light ຫາ Black ພ້ອມຕົວອຽງ ໑໒° ທຸກນ້ຳໜັກ — ປຸ່ມ B / I ໃນ Office ເອີ້ນໃຊ້ຟອນແທ້ອັດຕະໂນມັດ

v2.00 had one style only; Word had to synthesize bold/italic. v4 ships 12 real style-linked fonts.

ການຕັດຄຳຂຶ້ນແຖວໃໝ່

ຂໍ້ມູນພາຍໃນຟອນເສຍຫາຍ (ອ້າງວ່າຮອງຮັບທຸກພາສາໃນໂລກ) ເຮັດໃຫ້ບາງໂປຣແກຣມຕັດແຖວພາສາລາວຜິດພາດ

ແກ້ໄຂຕາມສູດຂອງຟອນ Saysettha (LaoScript) ແລະ ພິສູດແລ້ວດ້ວຍການທົດສອບຈິງໃນ Word, Excel ແລະ PowerPoint — ຕັດຄຳຖືກຂອບເຂດຄຳສະເໝີ

v2's OS/2 tables claimed every codepage in existence, confusing complex-script handling. v4 declares exactly Lao+Thai coverage — verified empirically in Office.

ຕຳແໜ່ງສະຫຼະ-ວັນນະຍຸດ

ໃນບາງໂປຣແກຣມ ວັນນະຍຸດລອຍຜິດບ່ອນ ຫຼື ຊ້ອນທັບສະຫຼະ ເພາະຟອນເກົ່າບໍ່ໄດ້ລົງທະບຽນກົດຕຳແໜ່ງແບບ DFLT

ກວດສອບຄົບ ໑,໒໐໔ ຊຸດປະສົມ (ພະຍັນຊະນະ×ສະຫຼະ×ວັນນະຍຸດ) ໃນທຸກນ້ຳໜັກ — ບໍ່ມີການຊ້ອນທັບແມ່ນແຕ່ຈຸດດຽວ

Added DFLT script registration (matching Saysettha) and weight-aware mark lifting; 1,204 combos × 12 fonts verified collision-free.

ການຕັດຄຳລາວແມ່ນໜ້າທີ່ຂອງ Word ບໍ່ແມ່ນຂອງຟອນ — ຟອນທຸກຕົວໃນໂລກບໍ່ສາມາດບັງຄັບ Word ຮຸ່ນເກົ່າໃຫ້ຕັດຄຳໄດ້ ເພາະລະບົບຕັດຄຳຢູ່ໃນໂຕ Word ເອງ:

✅ Microsoft 365 / 2021 / 2019 / 2016 — ຕັດຄຳລາວໄດ້ເອງ (ເປີດພາສາລາວຕາມຄຳແນະນຳຂ້າງລຸ່ມ)
⚠️ Word 2013 / 2010 — ລະບົບຕັດຄຳຮຸ່ນເກົ່າ (Uniscribe) ຕັດຄຳລາວບໍ່ສະຖຽນ — ຟອນນີ້ໃສ່ຂໍ້ມູນຊ່ວຍໃຫ້ເຮັດວຽກໄດ້ດີສຸດແລ້ວ (ແບບດຽວກັບຟອນ Saysettha) ແຕ່ບາງເຄື່ອງກໍຍັງບໍ່ຕັດ — ນີ້ບໍ່ແມ່ນຟອນເສຍ
❌ Word 2007 ລົງໄປ — ບໍ່ຮອງຮັບ

ວິທີແກ້ສຳລັບ Word 2010/2013: ໃຊ້ມາໂຄຣ LaoWrapMacro.bas (ໃຊ້ໄດ້ທຸກຮຸ່ນ) — ສ່ວນ Add-in Lao Text Fixer ໃຊ້ໄດ້ສະເພາະ Word 2016 ຂຶ້ນໄປ. ຖ້າເປັນໄປໄດ້ ແນະນຳອັບເກຣດເປັນ Office 2016 ຂຶ້ນໄປ ຈະຕັດຄຳໄດ້ທັນທີ

Lao line breaking is done by Word's engine, not the font — no font can force old Word to wrap. Word 2016+ wraps natively; Word 2010/2013 use the legacy Uniscribe engine and may still fail even though this font ships the same compatibility metadata as the Saysettha fonts. On 2010/2013 use the LaoWrapMacro (works on every version); the add-in needs Word 2016+. Upgrading Office fixes it outright.

Word ບໍ່ຕັດຄຳປະໂຫຍກຍາວ — ຂໍ້ຄວາມທັງກ້ອນຕົກລົງແຖວໃໝ່?

Microsoft 365 ຮຸ່ນປັດຈຸບັນຕັດຄຳລາວໄດ້ເອງ ຫາກຂອງທ່ານບໍ່ຕັດ: ໄປທີ່ File → Options → Language ໃນສ່ວນ Office authoring languages and proofing ກົດ Add a language… ເລືອກ ລາວ (Lao) ແລ້ວປິດ-ເປີດ Word ຄືນ ຈາກນັ້ນເລືອກຂໍ້ຄວາມລາວທັງໝົດ → Review → Language → Set Proofing Language → ລາວ

ໝາຍເຫດ: ຖ້າ Word ຂຽນວ່າ "Missing Proofing Tools — proofing is not available in Lao" ບໍ່ຕ້ອງກັງວົນ — ນັ້ນໝາຍເຖິງແຕ່ການກວດຄຳຜິດ (spell check) ເຊິ່ງ Microsoft ຍັງບໍ່ມີສະບັບພາສາລາວ ສ່ວນການຕັດຄຳຂຶ້ນແຖວໃໝ່ຍັງເຮັດວຽກປົກກະຕິ ເພາະເປັນຄົນລະລະບົບກັນ

ໃນ macOS: ເລືອກຂໍ້ຄວາມລາວ → ເມນູ Tools → Language → ລາວ (Lao) — ມາໂຄຣ LaoWrapMacro.bas ໃຊ້ໄດ້ໃນ Word for Mac ເຊັ່ນກັນ

ຖ້າຍັງບໍ່ຕັດ: ຕິດຕັ້ງ Lao Text Fixer — Word Add-in ຟຣີຂອງພວກເຮົາ (Windows / macOS / Word ໃນເວັບ, ບໍ່ແມ່ນມາໂຄຣ ບໍ່ມີຄຳເຕືອນຄວາມປອດໄພ) ກົດປຸ່ມດຽວແກ້ໄຂທັງເອກະສານ ຫຼື ດາວໂຫລດ LaoWrapMacro.bas ມາໂຄຣ VBA ສຳລັບເຄື່ອງທີ່ໃຊ້ອິນເຕີເນັດບໍ່ໄດ້

Modern M365 wraps Lao natively; if not, add Lao under Office authoring languages and proofing and tag the text via Review → Language. The "Missing Proofing Tools" notice only means no Lao spell-checker exists — wrapping is a separate engine and still works. Otherwise install our free Lao Text Fixer add-in (Windows/Mac/web, no macro warnings) or the VBA macro for offline machines.

ສະຫຼະ ຳ ຫາຍ ຫຼື ແຍກເປັນ "ໍ າ" ເວລາແປງເປັນ PDF?

ຕັ້ງແຕ່ v4.103 ຟອນໄດ້ຮັບການແກ້ໄຂໃຫ້ທົນທານຕໍ່ການແປງ PDF ຫຼາຍຂຶ້ນ (ທຸກ glyph ມີລະຫັດ Unicode ຄົບ) — ກະລຸນາອັບເດດຟອນເປັນຮຸ່ນລ່າສຸດ

ແນະນຳໃຫ້ໃຊ້ File → Save As → PDF ໃນ Word ຮຸ່ນໃໝ່ (ບໍ່ແມ່ນ "Microsoft Print to PDF") ຜົນອອກມາຈະສະແດງ ຳ ຄົບຖ້ວນ

v4.103 PUA-maps every glyph so PDF subsetters never drop the am-ring. Note: copying Lao text OUT of any PDF is unreliable industry-wide (engines decompose ຳ internally) — keep the .docx as the editable source.
